# Happ VPN Client (Графитовая тема)

Android VPN-клиент с **автоматическим определением протокола** по ссылке,
сгенерированной панелью управления для Happ.

## Как это работает

1. **Экран 1 — вставка ссылки.** Прямоугольник со скруглёнными углами: вставьте
   ссылку, предназначенную для Happ (`happ://…`, `vless://…`, `vmess://…`,
   `trojan://…`, `ss://…`, `wireguard://…`, `hysteria2://…` или https-ссылку на подписку).
   Как только приложение понимает, что ссылка полная и сервер отвечает на запрос —
   происходит **автоматический переход** во второе меню.
2. **Экран 2 — подключение.** Большая круглая кнопка по центру. Одно нажатие —
   поднимается VPN-туннель (Android `VpnService`), повторное нажатие — отключение.

## Поддерживаемые протоколы (авто-детект)

| Протокол      | Схема ссылки                          |
|---------------|---------------------------------------|
| VLESS         | `vless://…`                           |
| VMess         | `vmess://…` (base64 JSON)             |
| Trojan        | `trojan://…`                          |
| Shadowsocks   | `ss://…` / `shadowsocks://…`          |
| WireGuard     | `wg://…` / `wireguard://…`            |
| Hysteria2     | `hysteria2://…` / `hy2://…`           |
| Подписки Happ | `happ://…`, https-подписка (base64/JSON)|

## Дизайн

Полностью **графитовая палитра** (graphite / gunmetal): фон `#1B1D21`,
карточки `#2A2D32`, акцент `#9AA3AE`.

## Сборка APK одной командой (Kali Linux / Debian)

```bash
./build.sh
```

Скрипт сам установит OpenJDK 17, Android SDK (cmdline-tools, platform 34,
build-tools 34.0.0) и Gradle 8.7, создаст ключ подписи и соберёт релизный APK.

**Результат:** `happ-vpn-client.apk` в корне проекта.

Установка на устройство:

```bash
adb install happ-vpn-client.apk
```

## Требования

* Kali/Debian/Ubuntu с доступом в интернет (для скачивания SDK при первой сборке)
* ~2 ГБ свободного места

## Структура

```
app/src/main/java/com/happvpn/client/
├── ui/MainActivity.java          # два экрана: ввод ссылки → большая кнопка
├── protocol/ProtocolDetector.java # авто-определение протокола по ссылке
├── protocol/Node.java            # модель узла
└── tunnel/TunnelEngine.java      # VpnService + туннельный движок
```
